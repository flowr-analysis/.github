# Analyzing R Code to Improve Program Comprehension

We work on [_flowR_](https://github.com/flowr-analysis/flowr), a program analyzer for the R programming language, which helps users to write better R code and to understand existing sources.

If you want to check it out, it is probably best to try its **[VS Code](https://marketplace.visualstudio.com/items?itemName=code-inspect.vscode-flowr)** and **[Positron](https://open-vsx.org/extension/code-inspect/vscode-flowr) extension**, or its **[RStudio addin](https://github.com/flowr-analysis/rstudio-addin-flowr)**.
